Q10 — Custom pipe & directive

Minimal interview practice: pipe with args + attribute directive with inputs.

1. Pipe with arguments

{{ sample | truncate:18:'…' }}

Full: {{ sample }}

Truncated (18, …): {{ sample | truncate: 18 : '…' }}

Truncated (10, ---): {{ sample | truncate: 10 : '---' }}

2. Directive with arguments

<p [appHighlight]="bg" [textColor]="fg">…</p>

Highlight me — directive applies styles via HostBinding + inputs.

Say in interview

  • Pipe — transforms display value in templates; pass args after :; keep pure when possible.
  • Directive — adds behavior to a host element; configure with input() / @Input(); style via HostBinding.
  • Pipe = data transform. Directive = DOM/behavior. Component = UI + logic with template.
