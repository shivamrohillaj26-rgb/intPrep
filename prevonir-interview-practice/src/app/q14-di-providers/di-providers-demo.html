Q14 — Where is this service provided?

Do the five steps in order. The number after # is “which new ran.” Same # = same object. Different # = two objects.

Step 1 — providedIn: 'root' (whole app)

Look at the login box. Then open Home and come back.

Logged in as {{ login.name }}

LoginService instance #{{ login.instance }}

Expect: still #1 after you leave and return. One login for the SPA.

Step 2 — component providers: [ScratchPad] (each widget)

Add a pen on Desk A. Add a stapler on Desk B. Compare the two # numbers.

Expect: Desk A is #1, Desk B is #2. Pen does not appear on B. Each desk created its own pad. Login in Step 1 is still shared.

Step 3 — route providers vs this-page providers

+1 on both boxes. Note the two #s. Go Home, open Q14 again.

A. Route — PageNotepad in app.routes.ts

Instance #{{ notepad.instance }} · ticks {{ notepad.ticks }}

Expect after Home → Q14: same # and same ticks. Angular caches the route injector on the Route. Home still cannot inject(PageNotepad).

B. This page — VisitPad on the component

Instance #{{ visit.instance }} · ticks {{ visit.ticks }}

Expect after Home → Q14: new # and ticks back to 0. The page was destroyed, so its providers died. This is the “reset when I leave” behavior.

Step 4 — appConfig.providers (boot, still root)

Compare this # with Step 1 after you leave and come back.

BootStamp instance #{{ boot.instance }}

Registered in app.config.ts, not providedIn: 'root'.

Expect: stays #1 like login. Same count. Different bundle: app.config.ts always imports BootStamp, so the bundler cannot drop it. LoginService is only imported where used — unused providedIn: 'root' classes can be tree-shaken. See MD Step 4.

Step 5 — not provided

Read the box. FORGOTTEN is only an InjectionToken — nobody listed it in any providers array and it has no providedIn.

inject(FORGOTTEN, { optional: true }) → {{ forgotten === null ? 'null' : forgotten }}

Walk: page → route → root → NullInjector. Optional turns the throw into null. Drop optional and this page would not boot (NullInjectorError: No provider for FORGOTTEN).

Creating the token ≠ providing it. Same crash if a class is only @Injectable() with no providers entry.
