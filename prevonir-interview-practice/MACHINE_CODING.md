# Machine Coding Practice (Angular)

React-style machine coding from interview screenshots → Angular demos in this app.

## Routes

| Route | Task | What to say |
|---|---|---|
| `/q5` | Expand/collapse list | track open id, toggle, `@if` body |
| `/q6` | Reusable Button | `variant`/`size` inputs, `ng-content` |
| `/q7` | Virtualized big list | window math, only visible DOM nodes |
| `/q8` | File explorer (VS Code sidebar) | recursive tree, Set expand, select file |
| `/q9` | JWT + RBAC | jwtAuthGuard, roleGuard, Bearer interceptor |
| `/q4` | Typeahead | debounce + switchMap + async pipe |

## 30-minute drill

1. Rewrite Q5 from blank (8 min)  
2. Rewrite UiButton API + CSS variants (8 min)  
3. Explain Q7 math on paper, then code (10 min)  
4. Rewrite Q8 file explorer from blank (20–30 min) — deep guide `src/app/q8-file-explorer/README.md`, cheat sheet `FILE_EXPLORER.md`  
5. Speak React→Angular map — `../angular-interview-prep/REACT_TO_ANGULAR_MACHINE_CODING.md`
