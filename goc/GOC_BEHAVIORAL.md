# GOC behavioral + hypothetical (STAR)

Official coaching: [How We Hire](https://googleoperationscenter.com/how-we-hire/). They **want STAR** and they **will** mix past stories with “imagine that…”.

**Rule:** “I” not “we”. One metric if you have it. 60–90s, then stop.

---

## 1. Three stories to have cold (reuse Netradyne)

Fill names/numbers from memory before you walk in.

### A — Deadline / fail (they publish this example)

**Prompt:** Tell me about a time you failed to meet a deadline. What did you miss? What did you learn?

**Shape:**

- **S:** Release date vs late API / scope (iframe leftover, CMS-like “content not ready”).  
- **T:** You owned the UI slice.  
- **A:** Cut scope *with* PM, shipped behind flag, didn’t silent-slip quality. Root cause: didn’t surface risk at kickoff.  
- **R:** Shipped a smaller vertical; next project had a risk log Friday.  
- **Learn:** say the **process** you changed — GOC grades learning.

### B — Designer / “bridge graphical design and implementation” (JD)

**Prompt:** Tell me about a time you disagreed with a design or had to push back.

- Motion / blur on a dense table → INP / a11y.  
- You prototyped both, showed Performance panel, agreed reduced motion / `prefers-reduced-motion`.  
- Result: shipped, designer still owned look.

### C — Code quality / review (JD)

**Prompt:** Tell me about a time you raised the bar in a review or a prod bug.

- `trackBy` missing, subscription leak, or un-sanitized HTML.  
- You explained *why*, not “nit”.  
- Result: checklist or lint, no repeat.

**Lead / juniors:** if they ask leadership — pairing, PR comments, splitting a module so a junior could land it. Same as your OneTrust mentoring story but **don’t mention OneTrust**.

**Why leave Netradyne:** growth on Google-quality public UI + design systems + CMS-driven work; gratitude, no trash-talk.

## 2. Hypotheticals (think aloud — they score process)

GOC’s own ads example is ops-flavored. For **this role**, expect:

| Imagine… | Structure |
|---|---|
| Homepage LCP 6s, brand campaign Monday | Measure (Lighthouse/field) → biggest win first (image/LCP element, JS) → flag, don’t rewrite Angular overnight |
| CMS editor published broken module | Preview gap; feature fallback; rollback content vs FE; tell comms |
| Teammate skipped a11y on a component | Psychological safety + ticket + example fix; don’t only escalate |
| Designer Figma vs existing design tokens | Tokens win for scale; one-off only with expiry |
| Two Angular versions in an MFE | Shared singleton / align versions; isolation vs duplicate runtime |

**Their scoring (paraphrase of How We Hire):** understand the problem → gather info / root cause → options + tradeoffs → metrics → clear communication.
